Phase 0 冒烟（2026-11-03）：macOS + Chrome + 假麦克风通过延迟目标，具体数字见 `latency.md`。假麦克风没有真实扬声器回声，AEC、外放误打断与其他平台仍未测，DM-01 到 DM-06 保持待测。

每组的测试步骤：

1. 进入语音模式，说 3 句中文、1 句英文。
2. 让 Agent 朗读 30 秒，在播放中打断 3 次。
3. 记录感知延迟、打断停止延迟、误打断次数。
4. 连续使用 10 分钟，记录崩溃、卡死、音频泄漏。
